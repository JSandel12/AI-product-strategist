# Этап 6: Стратегические варианты и Red-Team критика

1. Сформируй минимум **3 содержательно разных варианта** на одном горизонте и для одной клиентской ситуации:
   - Вариант A: **Оставить как есть** (базовый сценарий без изменений — обязателен).
   - Вариант B: **Лёгкое / точечное изменение** (например, предупреждения/триггеры в существующем интерфейсе или условиях тарифа).
   - Вариант C: **Капитальное продуктовое изменение** (например, единый семейный центр управления / кросс-устройственный мониторинг).
   - Вариант D (или явный гейт): **Закрыть / остановить направление** (или критерий полного сворачивания инвестиций при недостижении порога).
2. Запусти субагента `.agents/subagents/red-team-critic.md` и сформулируй **сильные возражения** к каждому варианту (включая свой рекомендуемый!).
3. Чётко отдели `[ФАКТ | SRC-xx]` от `[ГИПОТЕЗА]`, `[ДОПУЩЕНИЕ]` и `[ПРОГНОЗ]`.
4. Подключи человека (руководителя продукта) для выбора/подтверждения направления перед упаковкой итоговой стратегии.
