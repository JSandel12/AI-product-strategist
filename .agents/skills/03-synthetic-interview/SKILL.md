# Этап 3: Интервью и модельные респонденты

1. Для реальных интервью: используй шаблон `knowledge/templates/interview_guide_template.md`, не собирай ПДн в репозиторий, фиксируй согласие собеседника.
2. Для модельных (ИИ) респондентов:
   - запусти субагента `.agents/subagents/synthetic-respondent.md` для 2–3 контрастных ролей (например: организатор семейной группы, участник-родственник с отзывом согласия, владелец роутера/нескольких SIM).
   - Проведи поведенческое интервью строго о «последнем случае», барьерах и привычных заменах (чат, автоплатёж, приложение устройства).
   - **ЖЁСТКОЕ ОГРАНИЧЕНИЕ:** каждый инсайт помечай `[СИНТЕТИЧЕСКАЯ ГИПОТЕЗА]` и явно указывай, что синтетические ответы **не доказывают спрос и распространённость** — только генерируют гипотезы для проверки на реальных данных.
