# Сценарий видеозаписи работы агента (до 9 минут)

**Цель видео:** показать жюри сквозной путь демонстрационного проекта на живом репозитории без склеек и «магии»: запрос -> уточнение -> исследование и расчёты -> варианты и стратегия -> **продолжение в новом чате** -> **пересмотр при новых данных**.

---

## Подготовка перед записью (1 минута до старта)
1. Откройте папку `MGIMO AI Project` в **Antigravity IDE** (в левом дереве видны `AGENTS.md`, `.agents/`, `knowledge/`, `tools/`, `projects/megafon-family-devices/`).
2. Откройте встроенный терминал и выполните быструю проверку (можно показать в начале видео):
   ```powershell
   uv run pytest -v
   ```
3. Для живой демонстрации старта и продолжения очистите или используйте свежий тестовый диалог (либо покажите уже подготовленные файлы, прогоняя живые команды CLI/MCP).

---

## План видео по таймкодам

### 0:00 – 1:10 | Знакомство с ИИ-папкой и разделением слоёв
- Покажите структуру репозитория:
  - инструкции (`AGENTS.md`, `.agents/skills/`, `.agents/hooks.json`, `mcp_config.json`);
  - методическая БЗ (`knowledge/`);
  - изолированные проекты (`projects/_template/` и `projects/megafon-family-devices/`);
  - состояние (`projects/megafon-family-devices/state/session_state.json`).
- Коротко проговорите: *«Это не чат-бот и не один длинный промпт, а переносимая ИИ-папка с детерминированным Python-ядром, хуками и MCP»*.

### 1:10 – 2:30 | Неоднозначный запрос, маршрутизация и уточнение задачи
- В чате агента введите размытый запрос:
  > *«У нас есть бриф в `projects/megafon-family-devices/inputs/primer_brifa.pdf`. У семейных групп и роутеров падает удержание, надо решить, что запускать в первую очередь и как довести валовую прибыль с 279 до 285 млн руб. Начни работу.»*
- Покажите, что агент:
  1. Маршрутизирует шаг (`route`) и использует экономичную модель для intake/PDF.
  2. Постранично читает `primer_brifa.pdf` (`extract-pdf`, с проверкой на prompt-injection).
  3. Задаёт только критичные уточняющие вопросы (приоритет ограничений Q2 = 3 чел.-мес., допустимость модельных интервью).

### 2:30 – 4:15 | Исследование, пробелы, модельные интервью и точные расчёты
- Покажите `research/sources.yaml` и `research/gaps.md` (честные `[НЕДОСТАТОК ДАННЫХ]`).
- Покажите `research/synthetic_interviews.md` — обратите внимание жюри на тег `[СИНТЕТИЧЕСКАЯ ГИПОТЕЗА]` и запрет доказывать ими спрос.
- В терминале (или через вызов MCP агентом) запустите:
  ```powershell
  uv run python -m tools.strategist_cli calc ab --baseline-rate 0.12 --mde 0.03 --weekly-units 400 --obs-days 7
  uv run python -m tools.strategist_cli calc economics --paid-months 14000 --direct-cost 25 --extra-opex 400000 --dev-capex 2200000
  ```
- Прокомментируйте результат: `3 276` групп, `9,19` недель, `13 474` доп. оплаченных месяца для закрытия разрыва `6 млн руб.`.

### 4:15 – 6:10 | Варианты с сильными возражениями и итоговая 5-частная стратегия
- Откройте `projects/megafon-family-devices/outputs/strategy_v1.md`:
  - покажите сравнение **Варианта A (Оставить как есть)**, **Варианта B (MVP сигнал + 1-клик довыдача)**, **Варианта C (Полный редизайн кабинета)** и **Варианта D (Закрыть направление)** с **сильными возражениями** к каждому;
  - покажите согласованность продуктовой и коммуникационной стратегий (без обещаний, нарушающих приватность или лимиты тарифа);
  - покажите таблицу 5 KPI с разрывом до цели, ресурсами Q1–Q4 и рисками;
  - запустите линтер качества в терминале:
    ```powershell
    uv run python -m tools.strategist_cli lint projects/megafon-family-devices/outputs/strategy_v1.md
    ```

### 6:10 – 7:40 | Продолжение после перерыва в НОВОМ чате
- **Закройте текущий чат** и откройте **совершенно новый чат** в Antigravity.
- Покажите файл `state/session_state.json` и напишите в новом чате всего одну фразу:
  > *«Продолжи работу по активному проекту с сохранённого места и покажи текущие расходы.»*
- Агент через `SessionStart` / `strategist_status` мгновенно восстанавливает контекст (`megafon-family-devices`, текущий этап, `cost_log.csv`: `35 800` токенов / `16,0 руб.`), не начиная всё заново.

### 7:40 – 9:00 | Пересмотр решения при новых данных (Доп. уровень)
- Покажите `inputs/q1_telemetry_update.md` (`SRC-04`: задержка биллинга выросла до `4 часов`, а поток составил `200` групп/нед. вместо `400`).
- Запустите пересчёт и пересмотр:
  ```powershell
  uv run python -m tools.strategist_cli revise --fact "Задержка биллинга до 4 часов и поток 200 групп/нед." --source-id SRC-04
  uv run python -m tools.strategist_cli calc ab --baseline-rate 0.12 --mde 0.03 --weekly-units 200 --obs-days 7
  ```
- Откройте `outputs/strategy_v2_revision_demo.md` и `decisions/adr_ledger.yaml`: покажите, как агент честно нашёл устаревшие выводы (`17,38 недель > 12 недель Q2`), поднял порог триггера с `10%` до `25%`, обновил текст обещания в коммуникации и сформулировал новое решение для руководителя.
- Завершите видео командой `uv run python -m tools.strategist_cli benchmark` (проверки 4/4, `SEED=42`).
